# Shawzin Golden Fixtures

Files under `Valid` are offline song-code fixtures for the supported Warframe recorded-song V1 variant. `community-reference.shawzin` is the short eight-note technical example documented by the Japanese Warframe Wiki; it is retained only as interoperability data, not as a bundled song. All other valid fixtures are synthetic.

Files under `Invalid` each isolate one parser failure. Tests never download fixture data.
